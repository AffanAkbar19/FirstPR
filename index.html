Your first step into open source.

FirstPR finds open issues in any public GitHub repository, puts the ones maintainers marked for newcomers first, and walks you through your first pull request.

Works with any public repository. No sign-in, no API key.

Show issues

Labels come from each project's maintainers. They are useful signals, not a promise that an issue is easy.

How it works

From a repository link to your first pull request, in three steps.

  1. Paste a repository

    Any public GitHub repository. FirstPR reads its open issues straight from GitHub's public API.

  2. Pick an issue

    Issues labeled “good first issue” or “help wanted” come first. Filters help you narrow the list.

  3. Follow your starter guide

    A clear path from reading the issue to opening your pull request, with commands you can copy.

Your first pull request

What FirstPR does

  • Reads open issues from public repositories using GitHub's REST API.
  • Shows issues labeled “good first issue” or “help wanted” first, and leaves out pull requests.
  • Builds a starter guide from each issue's title, description and labels, using simple rules.
  • Checks whether the project has a contributing guide and links to it.

What it doesn't do

  • It doesn't use AI, read the repository's code, or run tests.
  • It can't promise an issue is easy. Labels are the maintainers' signals.
  • It needs no sign-in or API key. Everything runs in your browser and talks only to GitHub's public API.
  • Without sign-in, GitHub allows 60 requests per hour per network. Each search uses 3 of them.
